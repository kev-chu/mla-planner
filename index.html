Cloud sync setup

Connect a free Supabase project to sync this timetable between devices. Your Supabase URL and anon/publishable key are safe to use in a browser app when Row Level Security is enabled as instructed below.

First: create your free Supabase project

  1. Go to supabase.com/dashboard and create a project.
  2. In Project Settings → API, copy the Project URL and anon/public key (or publishable key) into the fields above.
  3. Open SQL Editor → New query, paste the SQL below, and click Run.
  4. Return here, connect, then create an account with your email and password.

Run this SQL once in Supabase

create table if not exists public.class_schedules (
  user_id uuid primary key references auth.users(id) on delete cascade,
  schedule jsonb not null default '[]'::jsonb,
  updated_at timestamptz not null default now()
);

alter table public.class_schedules enable row level security;

create policy "Users can read their own schedule"
on public.class_schedules for select
using (auth.uid() = user_id);

create policy "Users can insert their own schedule"
on public.class_schedules for insert
with check (auth.uid() = user_id);

create policy "Users can update their own schedule"
on public.class_schedules for update
using (auth.uid() = user_id)
with check (auth.uid() = user_id);
